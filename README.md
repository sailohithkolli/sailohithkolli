## Hi, I’m Sai Lohith Kolli

I’m a software engineer with a background in enterprise reporting and test automation. I’m interested in applied AI and forward-deployed engineering. One question connects my recent Java projects: once an AI tool gives someone an answer or takes an action, how can they check the result?

### Start with the Task Manager AI Agent

[Task Manager AI Agent](https://github.com/sailohithkolli/taskmanager-ai-agent) lets a user create, list, complete, and delete tasks in plain language. For example, send `create a task called Buy groceries` to the chat endpoint, then list the tasks to check the result. The README includes [API examples](https://github.com/sailohithkolli/taskmanager-ai-agent#api-endpoints) and explains [design decisions](https://github.com/sailohithkolli/taskmanager-ai-agent#key-design-decisions), including how the API handles errors centrally.

### Two related projects

- [AgentOps](https://github.com/sailohithkolli/agentops) explores how to monitor AI agents and score response quality with an LLM judge.
- [DocuChat](https://github.com/sailohithkolli/docuchat) uses Jina embeddings and pgvector to retrieve document text for questions answered with Groq.
